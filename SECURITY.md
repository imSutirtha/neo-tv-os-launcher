# Security Policy

## Supported Versions

Only the latest release of Neo tvOS receives security patches and updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

Neo tvOS is built with privacy and offline security as core pillars:
- **Zero Telemetry**: No user data, crash logs, or analytics leave the device.
- **Local Settings**: Preferences and configurations remain entirely on device storage.

If you believe you have found a security vulnerability or security bug, please report it privately:

1. **Email**: Send vulnerability reports directly to **iamsgm10@gmail.com**.
2. **Details**: Please include:
   - Description of the issue and potential impact
   - Proof of Concept (PoC) or reproducible steps
   - Affected device / Android version
3. **Response Time**: You will receive an acknowledgment within 48 hours, followed by patch verification and release timeline.

Please do **NOT** report security issues via public GitHub Issues.
